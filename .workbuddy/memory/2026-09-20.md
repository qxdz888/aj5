
## 2026-09-20 — 主站 aj5 首屏提速（数据分层）

- 问题：主站打开慢。排查确认图片不慢（平均 63KB、已 lazy、缓存头正常），瓶颈在 HTML 93KB 中内联了全部 336 件商品数据
- 方案：数据分层 —— 首屏只内联少量数据，全量后台从 manifest.json 加载
  - update_gallery.py 新增 build_inline()：每分类前 3 张（保证切任意分类都有内容）+ 按序补足到 INLINE_TOTAL=80
  - 新增 LAZY_BLOCK（AUTO_LAZY_START/END 标记包裹，幂等注入）：后台 fetch manifest.json，按 id 去重 push 进 const shoes（const 数组可 push），并把绝对 URL 前缀剥成相对路径
    - 合并后：有搜索词→performSearch 重搜；分类视图→renderGallery 重渲染；全部视图→因 filteredShoes 与 shoes 同引用，仅刷新"加载更多"按钮
    - 用 setTimeout(loadAllShoes,0) 延后执行，避开 TDZ（脚本同步执行期 const 尚未初始化）
  - head 加 <link rel="prefetch" href="manifest.json">
  - loadMore 渲染模板：首屏前 8 张 eager + fetchpriority="high"，其余 lazy，统一 decoding="async"
- 结果：HTML 93KB → 56.4KB，内联 80 件 / 全量 336 件后台加载；node --check 语法校验通过
- 推送：与 github-actions bot 自动提交冲突 → checkout --ours 保留本地版 → push 6077b89，ls-remote 核实已同步
- 易错点：git status -sb 的 ahead/behind 因 tracking ref 陈旧会误报，以 git ls-remote 为准
